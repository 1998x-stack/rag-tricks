# 飞书：知识库问答与文档助手

> **证据状态：Unverified。** 本页为历史整理，尚未逐条核验；公司实践、组件名称与精确指标均不能直接作为已证实事实或通用基准。见本页「来源与证据」。

## 是什么

飞书知识库 RAG 系统为超 100 万家企业客户提供智能文档检索、
信息总结与跨文档问答服务。

系统累计存储超 5 亿份文档，涵盖：
- 结构化表格（预算表、人员列表、项目计划）
- 非结构化文本（制度文件、产品手册、培训材料）
- 图片注释（截图标注、流程图）
- 企业上传的 PDF/Word 文档（合同模板、制度文件）

通过多粒度索引、表格语义索引、权限适配等 RAG 技术，
将文档检索召回率从 60% 提升至 92%，
文档访问效率提升 7 倍，
企业员工培训时间减少 30%。

## 为什么重要

企业用户在知识库使用中面临三大痛点：

**第一，检索召回率低**：
传统关键词搜索无法理解语义。
例如查询"如何申请差旅费报销"，
无法匹配"差旅费用报销流程"文档，
召回率仅 60%。

**第二，阅读耗时长**：
文档内容复杂，用户需花费大量时间阅读长文档，
平均阅读时长 15 分钟才能获取关键信息。

**第三，跨文档整合难**：
若问题涉及多个文档（如"项目预算申请需参考哪些制度"），
用户需手动筛选整合多份文档内容，效率低下。

RAG 系统使超 80% 的企业客户反馈文档助手降低了信息获取成本，
跨部门信息协同效率提升 50%。

## 如何使用

### 知识库构建

**数据来源**：
- 飞书文档（含结构化表格、非结构化文本、图片注释）
- 企业上传的 PDF/Word 文档（制度文件、合同模板）
- 历史协作对话（提取"问题 - 解决方案"对）

**文档解析**：
使用 ByteDocParser 支持 PDF 中的表格、图片文字提取，
OCR 识别准确率 99.2%，
将非结构化文档转换为"文本 + 结构化数据"混合格式。

**分块策略**：
采用"文档结构 + 语义完整性"双维度分块：
- 标题级文档按"章节 - 子章节"分块
- 长文本按"段落 + 核心语义单元"分块
- "预算申请流程"作为独立分块
- 表格数据按"表格标题 + 行数据"结构化分块

**向量生成**：
使用云雀 - Base (7B) 嵌入模型，
对文本分块生成 768 维向量，
对表格分块生成"表格结构向量 + 内容向量"混合表示。

**向量数据库**：
采用 ByteVectorDB + Redis 缓存架构，
热点文档（近 7 天访问 ≥ 10 次）向量存储在 Redis，
冷文档向量存储在 ByteVectorDB，
总规模 50 亿级，检索响应时间 ≤ 800ms。

### RAG 系统流程

1. **查询理解**：
   - 意图识别：文档检索 / 信息总结 / 跨文档问答
   - 实体提取：识别差旅费报销、项目预算、2024 Q3 等关键实体
   - 查询扩展：短查询通过 LLM 生成扩展查询，提升召回率

2. **检索策略**：
   - 文档检索：混合检索（语义检索 + 关键词检索）+ 表格检索
   - ByteBM25 匹配文档标题和标签
   - 信息总结：相关性排序 + 冗余过滤，保留 Top5 核心分块
   - 跨文档问答：拆解子问题分别检索再整合结果

3. **生成优化**：
   - 使用云雀 - Base (7B) 模型
   - latency 控制在 800-1200ms
   - 提示模板支持分章节总结、Markdown 表格、步骤列表等格式

### 关键优化点

**表格语义索引**：
将表格列名、行数据转换为文本描述再生成向量。
如"表格标题：2024 年差旅费报销标准；
列名：交通方式、报销上限、凭证要求；
行数据：高铁 - 500 元/次 - 需提供车票"。
确保"高铁报销上限"等查询精准检索到对应表格。
生成时支持将表格数据还原为 Markdown 表格格式。

**文档权限适配**：
飞书文档存在精细化权限控制（部门可见、个人私有）。
系统接入飞书权限中心，检索时过滤无权限文档。
生成回答时标注文档权限状态，
如"该回答基于《部门预算制度》（仅市场部可见）生成"，
避免权限泄露。

**多轮对话记忆**：
在多轮对话场景（如用户先问"报销流程"再问"审批需要多久"），
通过对话历史缓存记录前序检索结果。
后续查询优先基于历史文档生成回答，
多轮对话 latency 降低 50%，
回答连贯性提升 40%。

### 业务效果

- **检索效率提升**：召回率 60% → 92%，找到信息的时间 15 分钟 → 2 分钟
- **用户体验优化**：事实准确率 94%，格式符合度 98%，满意度 70% → 91%
- **企业协作效率**：培训时间减少 30%，跨部门协同效率提升 50%
- **客户反馈**：超 80% 企业客户认为降低了信息获取成本

## 常见误区

**忽略表格数据**：
企业文档大量信息以表格存在，
仅做文本向量化会导致表格结构信息丢失。
必须设计专门的表格语义索引。

**权限控制缺失**：
飞书文档权限精细，不做权限过滤会导致越权访问。
必须接入权限中心检索时过滤。

**短查询处理不当**：
用户常输入"报销""流程"等短查询，
应启用查询扩展功能通过 LLM 生成扩展查询。

**信息总结冗余**：
长文档检索结果过多直接传入生成模型
会导致模型注意力分散。
应进行相关性排序，仅保留 3-5 个核心片段。
