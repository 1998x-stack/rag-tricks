# RAG 分层排障流程

> Evidence: Derived。按可观测证据排查，不预设所有错误都来自模型。

## 先保留失败样本

记录 query_id、请求时间、测试身份、语料/索引/模型版本、召回结果、过滤理由、最终上下文、回答引用、各阶段耗时与错误码。调试记录需脱敏并沿用源数据的访问权限。

## 逐层缩小范围

| 现象 | 首先检查 | 验证实验 | 后续动作 |
|---|---|---|---|
| 知识根本没入库 | 源文档、解析内容、失败队列、版本 | 以文档 ID 查源与索引，比较内容哈希 | 修复采集、解析或索引发布 |
| 入库但未召回 | 查询与文档 embedding 版本、过滤条件、分块 | 在授权子集中用精确检索对照 ANN；检查词法检索结果 | 区分模型相关性、ANN 参数与过滤损失 |
| 候选中有答案，最终上下文没有 | 重排、去重、压缩、token 截断 | 保存每阶段文档 ID 和证据片段去向 | 调整候选预算与上下文选择 |
| 上下文有正确证据，回答仍错误 | 否定、时间范围、指令冲突、引用映射 | 使用人工选定的正确上下文回放同一查询 | 分别评估 Prompt 与生成模型 |
| 回答使用旧知识 | 索引版本、缓存键、TTL、失效通知 | 绕过缓存并指定新索引重放 | 修复版本路由或缓存失效 |
| 尾延迟高 | 排队、慢依赖、重试、长输出、缓存未命中 | 对比同样负载和长度下各阶段耗时 | 处理瓶颈并复测成功率与成本 |
| 权限变更后仍返回内容 | 检索过滤、缓存隔离、引用访问检查 | 两个不同授权身份重放同一问题 | 修复权限传播并加入回归样本 |

人工提供正确上下文只是诊断生成能力的实验，不代表真实检索已经达标。精确检索对照也必须使用同一模型、相似度定义和过滤集合。

## 完成修复的条件

- 原失败样本可以复现，修复后通过，而且相邻切片没有明显退化。
- 能说明原因与证据，例如“证据在重排后被移除”，而不只是“换模型后好了”。
- 更新固定评估集、配置版本、回滚条件和监控项。
- 按[离线实验协议](experiment-protocol.md)保存结果；涉及历史页面结论时同步更新来源登记。
