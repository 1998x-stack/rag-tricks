# 数据收集与清洗

> **证据状态：Unverified。** 本页为历史整理，尚未逐条核验；公司实践、组件名称与精确指标均不能直接作为已证实事实或通用基准。见本页「来源与证据」。

## 是什么

数据收集与清洗是 RAG 系统构建知识库的第一步，涵盖从多渠道采集原始数据到通过清洗规则去除噪声的全过程。字节跳动的数据收集渠道分为三大类：内部知识库（产品文档、技术手册、客服知识库）、行业数据库（订阅金融、医疗等专业数据库获取权威报告与统计数据）、公开网络资源（通过爬虫技术从权威网站、新闻媒体、行业论坛采集）。清洗环节则包含去重、纠错、缺失值处理和无效数据过滤四个核心步骤，形成标准化的 ETL 流程。

## 为什么重要

RAG 系统的检索质量直接取决于知识库中的数据质量。低质量数据会导致多重问题：检索结果中噪声过多，降低回答准确率；重复数据增加向量存储成本和检索延迟，严重时可使存储成本膨胀 15% 以上；拼写错误和语法问题影响嵌入模型的语义理解，导致语义相似的文本被映射到错误的向量空间区域；缺失值和过期信息使生成层产生误导性回答，给用户传递已失效的信息。字节跳动的经验表明，数据清洗环节每投入 1 分的精力，可以在后续检索和生成阶段节省至少 5 分的纠错成本。清洗越早介入，下游环节的返工成本越低。

## 如何使用

**数据收集渠道：**

- **内部知识库**：产品文档、技术手册、客服常见问题解答（FAQ）、运营知识库。这些数据与业务紧密相关，语义匹配度高，在智能客服场景中可直接用于快速响应用户咨询。内部数据通常质量最高，应优先纳入知识库。
- **行业数据库**：订阅专业行业数据库获取权威报告、研究论文、统计数据和公司财报。在金融业务线，通过金融数据提供商获取最新市场行情和公司财报信息，为投资决策分析提供数据支持。行业数据权威性高但格式多样，需要额外的格式转换和清洗处理。
- **公开网络资源**：利用网络爬虫从权威网站、新闻媒体、行业论坛采集，严格遵守法律法规和网站的使用条款。在资讯业务中，从各大新闻网站收集时事新闻，为用户提供及时准确的信息。公开数据量大面广，但噪声最多，清洗规则需要最严格。

**数据清洗四步流程：**

1. **去除重复数据**：使用哈希算法（如 MD5、SHA256 全文哈希）识别并删除完全相同的数据记录。在处理大量新闻文章时，去除重复发布的内容，避免后续冗余计算。对于转载类内容（如同一新闻的不同来源版本），需在向量层面辅助去重，哈希去重仅作为第一步。

2. **纠错拼写和语法错误**：利用 NLP 工具（如 NLTK、Stanford CoreNLP）对文本进行检测和纠正，提高文本可读性和语义理解准确性。字节跳动自研的中文拼写纠错模型准确率达 98% 以上，可自动纠正常见的错别字（如"飞书文挡"→"飞书文档"）、同音字混淆等问题。

3. **处理缺失值**：对结构化数据中的缺失值，根据数据类型和业务需求选择合适的处理方法：
   - 数值型数据：可使用均值、中位数或众数填充，也可根据业务上下文做插值。
   - 文本型数据：若缺失值较多且对业务影响不大，考虑直接删除相关记录。
   - 时间型数据：可通过相邻记录推断或标记为"未知"。
   - 选择填充还是删除的策略取决于缺失率：缺失率低于 5% 可填充，高于 30% 需评估该字段的保留价值。

4. **过滤无效数据**：根据业务规则过滤掉不符合要求的数据。例如，在客服知识库中，删除已经失效的解决方案或过期的信息；在新闻资讯库中，过滤掉来源不可靠、内容质量低下的文章。过滤规则应随业务更新而调整，建议每季度审视一次规则有效性。

## 常见误区

- **收集即用，跳过清洗**：直接从业务系统拉取数据导入索引，忽略去重和纠错，导致检索结果中重复内容占比高、向量存储浪费。初期看似省时，后期需要花数倍的精力处理质量问题。
- **清洗规则一刀切**：所有数据类型使用相同清洗策略，导致结构化数据（如 SQL 导出表格）中有效特殊字符被误删，或者非结构化文本中关键格式信息（如 Markdown 标题标记、代码块标识）被过度清洗。正确的做法是为每种数据类型定制清洗规则集。
- **忽略时效性过滤**：仅关注文本质量，未建立时效性规则，导致知识库中存有过期的解决方案和政策信息，生成层给出已失效的建议。至少应标记每条数据的采集时间和有效期，检索时可根据查询场景过滤过期内容。
- **去重粒度过粗**：仅做全文本哈希去重，忽略语义相似但表述不同的重复内容（如同一新闻的不同转载版本，正文相同但标题和首段经过改写），导致向量库中存在大量冗余。应结合哈希去重（精确匹配）和向量相似度去重（模糊匹配）两阶段进行。
- **缺失值无差别填充**：对所有缺失字段都用"无"或空字符串填充，导致嵌入模型将这些无意义的填充文本也编码进语义空间，造成向量表达的"语义偏移"。
