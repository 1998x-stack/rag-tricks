# 文本预处理

> **证据状态：Unverified。** 本页为历史整理，尚未逐条核验；公司实践、组件名称与精确指标均不能直接作为已证实事实或通用基准。见本页「来源与证据」。

## 是什么

文本预处理是将原始文本转化为适合嵌入模型和检索系统处理的标准化格式的过程。字节跳动在 RAG 系统中的文本预处理包含两大核心任务：分词与词性标注、文本归一化（大小写转换、数字标准化、特殊字符处理）。预处理质量直接影响后续向量生成时语义表达的准确性，是连接数据清洗和向量生成的桥梁环节。

## 为什么重要

原始文本中存在大量格式噪声和语言歧义，如果不经过预处理直接送入嵌入模型，会导致向量表示中混入无关信息，降低检索精度。具体风险包括：同一词汇的大小写形式不同可能被模型视为不同语义，在向量空间中产生不必要的距离偏差；不同格式的数字（"1,000" vs "1000"）在语义空间中的表示产生偏移，影响数值敏感类查询的匹配；未处理的全角/半角差异造成字符级别的不一致，干扰模型的注意力分配。在中文场景中，分词粒度更是直接影响语义理解——"武汉市/长江大桥"和"武汉/市长/江大桥"是截然不同的语义拆分，错误的分词会导致检索完全偏离用户意图。

## 如何使用

**分词与词性标注：**

- 使用基于深度学习的分词工具（如结巴分词的改进版本），能准确处理中文的复杂词汇和短语。相较于传统基于词典的最大匹配法，深度学习分词器对未登录词（如新出现的产品名、网络用语）的识别能力更强。
- 支持自定义词典，方便加入业务特定术语，如抖音电商的产品名（"DOU分期"）、飞书的功能名称（"多维表格"）、金融术语（"量化宽松"）。自定义词典是提升分词准确率最高 ROI 的操作之一。
- 词性标注工具通常与分词工具集成，推荐哈工大 LTP 工具包，可高效完成词性标注（名词、动词、形容词等）。LTP 在中文词性标注任务上具有业界领先的准确率，支持细粒度标注标签集。
- 词性标注结果有助于理解文本的语法结构和语义信息，为后续文本分析提供支持。例如：名词短语往往承载核心信息，动词短语表示动作关系，词性信息可用于优化检索时的关键词权重分配。

**文本归一化：**

1. **大小写转换**：将所有文本统一转换为大写或小写，消除因大小写不同导致的文本差异。例如，"Hello" 和 "hello" 统一转换为 "hello"。注意：对产品名称（如 "iPhone"）和专有名词（如 "BERT"）需要特殊处理——在某些场景中保持原始大小写更有利于实体识别。
2. **数字标准化**：将不同格式的数字表示统一化，如 "1,000" 和 "1000" 都转换为 "1000"；百分数 "50%" 转换为小数 "0.5"；分数 "1/2" 标准化为 "0.5"。这有助于后续处理中对数字进行准确比较和分析。在金融研报场景中，数字标准化直接影响"增长率超过 50%"这类查询的匹配准确性。
3. **特殊字符处理**：去除文本中无语义作用的特殊字符（如 @、#、* 装饰符号），或将特殊符号转换为统一表示（如 & → "and"、"$" → "美元"、"%" → "百分之"）。保留在特定场景下有语义作用的标点（如引号表示引用、问号表示疑问、破折号表示说明）。同时统一全角和半角字符，将全角英文字母、数字和标点转换为半角形式，消除格式差异带来的干扰。

**预处理流程编排建议：**

预处理各步骤有依赖关系，建议按以下顺序编排：全角→半角转换 → 特殊字符过滤/替换 → 大小写统一 → 分词 → 词性标注 → 数字标准化。数字标准化放在分词之后，避免数字格式差异影响分词结果。特殊字符过滤放在最前面，避免特殊字符干扰后续的字符级别转换。

## 常见误区

- **分词粒度选择错误**：业务场景需要细粒度分词（如医疗术语"靶向药治疗"应作为整体保留）却使用粗粒度模式，导致"靶向药治疗"被错误拆分为"靶/向/药/治疗"，完全丢失了术语的语义完整性。最佳实践是根据业务领域配置分词粒度，专业术语密集的场景倾向粗粒度（保留完整术语），通用文本场景倾向细粒度。
- **忽略自定义词典**：仅使用通用分词模型，未加入业务术语，导致"飞书文档"被拆分为"飞/书/文档"，"DOU分期"被拆分为"DOU/分期"。每接入一个新业务线，应优先补充该业务的核心术语词典。
- **过度归一化**：将所有特殊字符无差别删除，导致代码片段、SQL 查询、API 文档中大量含特殊语义的字符（如 `<table>` 中的尖括号、`{"key":"value"}` 中的花括号和引号）被误删，完全破坏了代码类文档的可读性。应构建白名单机制，只过滤明确无意义的字符。
- **大小写信息丢失**：在区分大小写有意义的场景（如产品名 "iPhone" vs "iphone"、模型名 "BERT" vs "bert"）中强制统一大小写，丢失了实体识别线索。建议做大小写感知的分词，在归一化前先记录专有名词的大小写模式。
- **数字格式保留原始格式**：未做数字标准化，导致"50%"和"0.5"在向量空间中被映射到不同区域，检索时语义匹配失败。包含百分比的查询和包含小数的文档无法建立语义关联。
