# 引言

## 概述

大语言模型（LLM）在信息处理领域带来了革命性变化，但同时也暴露出对训练数据之外的知识缺乏了解、容易产生幻觉等核心问题。检索增强生成（Retrieval-Augmented Generation, RAG）技术通过引入外部知识库的信息，显著提高了模型回答的准确性和可靠性。

字节跳动作为在人工智能领域具有深厚技术积累的公司，已在众多业务线中广泛应用 RAG 技术。本类别整理了 RAG 技术的基本原理、与其他技术的对比，以及字节跳动各业务线的应用现状。

- [[rag-vs-ir|RAG vs 信息检索]] — 分析 RAG 在自然语言处理能力和知识整合能力上对传统信息检索的超越

## 核心实践

| 实践 | 场景 | 要点 |
|------|------|------|
| 三步建链法 | RAG 系统搭建 | 先建索引、再配检索、最后调生成，每一层结果验证后再进入下一层 |
| 知识库优先 | 业务场景选择 | 有高质量知识库的业务优先落地 RAG，数据质量决定系统上限 |
| 混合评估体系 | RAG 效果评估 | 人工评估（准确性、完整性、逻辑性）+ 自动评估（BLEU、ROUGE）结合 |
| 实时知识更新 | 动态业务场景 | 利用 RAG 的实时检索能力解决 LLM 知识滞后问题，无需重新训练模型 |
