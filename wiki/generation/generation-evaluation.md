# 生成层效果评估

## 是什么

生成层效果评估是通过"质量-效率-成本"三维指标体系，结合自研评估工具 ByteGenEval 和分级评估流程（每日轻量 + 每周全量 + 每月复盘），系统化衡量生成层表现并驱动持续优化的闭环机制。

## 为什么重要

没有评估就没有优化方向。生成层是 RAG 系统直接面向用户的部分，其质量直接影响用户体验和业务效果。但生成质量的评估比检索评估更复杂——不能仅靠自动指标，需要人工评估的深度参与。字节跳动通过分级评估体系，在控制评估成本的同时确保质量的持续改善，使抖音电商场景的生成回答平均分从 7.2 提升至 8.8 分。

## 如何使用

### 三维评估指标体系

**质量指标**：
| 指标 | 要求 | 说明 |
|------|------|------|
| 事实准确率 | 核心业务 ≥ 90% | 人工标注生成回答中与检索信息一致的内容占比 |
| 幻觉率 | 核心业务 ≤ 5% | 生成回答中包含检索信息外内容的占比（越低越好） |
| 用户满意度 | 核心业务 ≥ 85% | 用户反馈"有用"的比例 |
| 格式符合度 | 核心业务 ≥ 95% | 生成回答满足提示模板格式要求的比例 |

**效率指标**：
- **生成 latency**：从模型接收提示到输出回答的平均时间，实时业务要求 ≤ 1 秒，非实时业务要求 ≤ 3 秒
- **QPS 承载能力**：单 GPU 集群单位时间内可处理的生成请求数，核心业务要求 ≥ 5000
- **可用性**：生成服务正常运行的时间占比，核心业务要求 ≥ 99.99%

**成本指标**：
- **单位请求成本**：处理 1000 次生成请求的 GPU 资源成本（元/千次），核心业务要求 ≤ 0.5 元/千次
- **GPU 资源利用率**：GPU 实际计算时间占总时间的比例，要求 ≥ 70%

### ByteGenEval 评估平台

字节跳动自研的生成层评估平台 ByteGenEval 支持：
- 批量导入"查询-检索信息-生成回答"数据，自动计算事实准确率（通过对比生成文本与检索文本的语义相似度）、格式符合度（通过正则匹配模板格式要求）
- 接入用户反馈数据，自动统计用户满意度、幻觉率（结合人工标注验证）
- 实时监控效率指标（latency、QPS、可用性），生成可视化仪表盘（latency 分布直方图、QPS 时序曲线）
- 计算成本指标，结合 GPU 资源使用数据（每张 GPU 的小时租金、处理请求数），自动生成单位请求成本报表

### 分级评估流程

**每日轻量评估**：
- 自动计算效率指标、用户满意度
- 若指标异常（如 latency 突然升高），触发告警，工程师需 1 小时内响应排查

**每周全量评估**：
- 人工标注 1000 条回答，计算事实准确率、幻觉率、格式符合度
- 统计成本指标，生成《生成层周度评估报告》

**每月优化复盘**：
- 对比近 4 周评估指标，分析优化效果（如微调后事实准确率是否提升）
- 总结问题与改进方向，更新《生成层优化 roadmap》

## 常见误区

- **仅依赖自动评估**：自动评估（语义相似度比对）无法检测"逻辑正确但表述错误"的细微问题，必须结合人工评估。建议自动评估覆盖每日监控，人工评估用于每周深度诊断。
- **用户满意度的置信度问题**：主动打分的用户往往是有强烈情绪（极满意或极不满）的，沉默用户占多数。需要结合 CTR、停留时间等行为指标综合判断。
- **成本指标与质量指标的冲突**：降低模型参数量可降低成本但可能降低质量。需要设定"质量不降级"的硬约束（如事实准确率下降不得超过 2%），在此约束下优化成本。
