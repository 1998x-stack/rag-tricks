# 混合检索

## 是什么

混合检索是将语义检索（向量检索）和关键词检索（ByteBM25）的结果进行融合，综合两种检索方式的优势，在不同查询场景下获得最优检索效果。字节跳动采用**加权融合**和**重排序融合**两种方式，并支持基于用户查询类型的**动态权重调整**。

## 为什么重要

语义检索擅长理解查询的深层含义但可能遗漏精确关键词匹配，关键词检索擅长精确匹配但不理解语义。混合检索让两者优势互补：在金融研报检索场景中，混合检索比单一语义检索的 MAP 提升 9%。更重要的是，通过动态权重调整，不同类型查询（语义型/关键词型/混合型）都能获得最优的检索策略配比。

## 如何使用

### 加权融合

对语义检索结果（按相似度得分排序）和关键词检索结果（按 ByteBM25 得分排序）分别赋予权重，计算每条结果的综合得分，按综合得分排序后返回。

默认权重为语义检索 0.6、关键词检索 0.4：
```
综合得分 = 语义得分 × 0.6 + 关键词得分 × 0.4
```

### 重排序融合

将语义检索和关键词检索的 Top-100 结果合并，去除重复项后，使用轻量级的重排序模型（LinearSVM、Transformer 小模型）对结果进行重新排序。重排序模型的特征包括：
- 语义相似度
- 关键词匹配度
- 文档权威性（发布时间、来源可信度）
- 用户历史点击数据

在飞书搜索场景中，重排序融合策略使 MAP 提升 9%。

### 动态权重调整

基于用户查询的类型动态调整融合权重。通过 LLM 将查询分为三类：
- **语义型**（如"解释抖音推荐算法的原理"）：语义检索权重提升至 0.8
- **关键词型**（如"抖音电商保证金金额"）：关键词检索权重提升至 0.7
- **混合型**（如"2024 抖音电商年货节活动时间"）：使用默认权重 0.6:0.4

动态权重调整确保不同类型查询都能获得最优检索效果。

## 常见误区

- **权重不是越高越好**：语义检索权重过高会引入噪声（匹配语义但内容不相关的文档），关键词权重过高则会遗漏语义相关的文档。默认 0.6:0.4 是一个经过验证的平衡点，但仍需根据业务数据 A/B 测试调整。
- **重排序融合不是必要的**：对于简单场景（如 FAQ 问答），加权融合已足够。重排序模型有额外的训练和维护成本，仅在复杂检索场景（如飞书知识库、金融研报）中推荐使用。
- **动态权重依赖 LLM 分类准确性**：LLM 对查询类型的分类错误会直接导致权重配比偏差。建议在 LLM 分类后加一层阈值校验（如分类置信度 < 0.7 时回退到默认权重）。
