# 新手工程师入门指南

## 是什么

字节跳动为帮助新入职工程师快速掌握 RAG 技术栈而编写的系统化入门指南，涵盖 3 个月学习路径、常见问题与解决方案、学习资源与支持渠道。目标是让新手在 3 个月内可独立参与业务线 RAG 项目。

## 为什么重要

RAG 系统涉及数据处理、索引构建、检索策略、生成优化、运维监控等多个模块，技术栈复杂。无系统化入门路径，新手容易出现"不知从何入手""遇到问题无法定位"的困境，学习周期可能延长到 6 个月以上。结构化的入门指南将上手时间压缩至 3 个月。

## 如何使用

### 第 1 个月：基础认知与工具熟悉

**理论学习：**
- 必学文档：《RAG 技术白皮书》《RAG 系统架构设计规范》《向量数据库使用手册》
- 核心课程：内部学堂"RAG 基础理论""嵌入模型原理""检索算法实践"，每周 2 课时，课后测验正确率 ≥ 80%
- 行业论文：阅读《Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks》《Real-World RAG Systems》等

**工具实践：**
- 在开发环境部署迷你版 RAG 系统（ByteVectorDB 单机版 + 云雀-Tiny 模型），完成"本地文档上传 → 索引构建 → 查询检索 → 回答生成"全流程
- 熟练使用 ByteMonitor（查看监控指标）、ByteLog（查询日志）、ByteRetrievalEval（评估检索效果）
- 实操任务：查看某业务线检索 latency 趋势、定位一条检索失败日志

### 第 2 个月：核心模块实践

**数据层与索引层实践：**
- 任务 1：处理 1000 份测试文档（文本 + 表格 + 图片），使用 ByteDocParser 解析，调用 DataCleaner 清洗，验证错误率 ≤ 0.5%
- 任务 2：为清洗后数据构建索引，配置 ByteEmbeddingService（云雀-Base 模型）与 ByteVectorDB（2 个分片），监控索引构建耗时与向量生成准确率

**检索层与生成层实践：**
- 任务 1：设计 100 条测试查询（含短查询、多意图查询），调用 ByteRetrievalKit 实现混合检索，计算 Recall@10 与 Precision@10，优化参数使指标达标
- 任务 2：使用 GenTemplateLibrary 的"文档总结模板"，生成 100 条查询的回答，通过 QualityGuard 校验生成质量，分析并修正幻觉率高、格式错误等问题

### 第 3 个月：业务线项目参与

**需求理解与方案设计：**
- 参与业务线需求评审会，理解具体业务场景
- 协助资深工程师编写《RAG 系统设计方案》，包含数据来源、索引策略、生成优化点

**功能开发与测试：**
- 负责 1-2 个非核心功能开发（如检索结果导出、回答格式自定义），代码通过率 ≥ 95%
- 编写测试用例并执行功能测试、性能测试，输出《测试报告》

**上线与运维支持：**
- 参与系统灰度上线，监控线上指标（响应时间、成功率），协助处理简单告警
- 总结项目经验，输出《新手实践总结》

## 常见误区

1. **跳过基础直接上手业务项目**。不熟悉 ByteVectorDB、ByteEmbeddingService 等核心组件，遇到问题时无法独立定位，反复依赖导师指导。
2. **忽视工具熟练度训练**。ByteMonitor、ByteLog、ByteRetrievalEval 是日常排障的核心工具，不熟练会导致问题定位耗时长。
3. **只看文档不动手实践**。RAG 系统是工程系统，"本地搭建 → 数据导入 → 问题排查"的实操经验远比阅读文档重要。
4. **第 3 个月期望独立负责核心模块**。新人应从小功能开发、测试、灰度监控等边缘任务切入，逐步积累对全链路的理解。

## 常见问题速查

| 问题 | 解决方案 |
|------|----------|
| PDF 复杂表格提取后格式混乱 | ByteDocParser 开启"复杂表格解析"模式，调用表格结构修复接口 |
| 语义重复数据清洗不彻底 | DataCleaner 添加语义去重规则，相似度 ≥ 0.95 判定为重复 |
| 短查询检索召回率低 | ByteRetrievalKit 启用查询扩展，LLM 生成扩展查询，调整关键词权重 0.4→0.6 |
| 生成回答含幻觉（检索外内容） | GenTemplateLibrary 添加事实锚定指令，QualityGuard 开启幻觉检测（阈值 < 0.6） |
| 生成格式不符合要求 | 修改提示模板明确格式要求，添加示例引导，格式符合度可提升至 98% |

## 学习资源与支持渠道

- **文档库**：内部 Wiki"RAG 技术专区"，包含架构文档、组件手册、项目案例
- **代码库**：GitLab"RAG 技术中台"仓库，可查看组件源码、调用示例、测试脚本
- **培训课程**：内部学堂"RAG 工程师进阶路径"，涵盖多模态 RAG、Agent 集成
- **技术中台支持群**：日常问题群内提问，中台工程师 1 小时内响应
- **导师制度**：每位新手分配资深工程师导师，每周 1 次 1 对 1 指导
- **月度分享会**：每月举办"RAG 技术实践分享会"，各业务线工程师分享项目经验
